# Публичная MIDI-подборка

Отдельный список разрешённых файлов для публичного режима Web-MIDI-Player.
Восемь MIDI получены непосредственно из Mutopia Project. На страницах
каждой включённой редакции указан статус **Public Domain**; Mutopia объясняет
его как передачу автором набора своего вклада в общественное достояние.
Общие условия: https://www.mutopiaproject.org/legal.html.

Девятая пьеса — «Полёт шмеля» Римского-Корсакова. MIDI подготовлен из
фортепианной редакции Noctave, опубликованной издателем под **CC0 1.0**.
Декларация есть и на странице издателя, и внутри оригинального MusicXML.
Это отдельная редакция; локальный MIDI с MIDIWorld с неподтверждёнными
правами в подборку сайта не копировался.

Исходная музыка Бетховена, Моцарта, Джоплина, Сати, Гуно и Римского-Корсакова написана
в XVIII — начале XX века; сведения об изданиях и датах композиторов
сохранены в manifest.json. В Ave Maria Гуно использована прелюдия
Иоганна Себастьяна Баха (1685–1750).

## Подготовка «Полёта шмеля»

Оригинал `sources/rimsky-korsakov-flight-of-the-bumblebee.mxl` сохранён
побайтно. Это фортепианное переложение оркестровой интермедии из
«Сказки о царе Салтане», с восстановленным издателем повтором тактов 75–85.
Сохранены обе фортепианные партии, темп 144 BPM и выписанный повтор:
113 тактов в развёрнутой последовательности, примерно 1:34 звучания.

Для воспроизведения преобразования установите в отдельное окружение Python
`music21==9.9.1` и `defusedxml==0.7.1`, затем запустите:

`python public-library/tools/build-bumblebee.py`

Скрипт проверяет SHA-256 исходных нот и сохраняет MIDI в `midi/`.
MIDI получен механическим преобразованием с раскрытием повтора и
объединением залигованных нот; ручных изменений нот нет. Он также
передан под [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).
Для обычной сборки сайта Python и music21 не нужны: готовые MIDI и ноты
хранятся в Git и проверяются по контрольным суммам.

## Сохранение при очистке репозитория

Эта подборка намеренно хранится в Git и используется библиотекой на сайте.
Сохраняйте весь каталог `public-library/`, включая `midi/`, `sources/`,
`manifest.json` и эту документацию, при уборке файлов, сокращении размера
репозитория и переписывании истории. Не удаляйте её как личную коллекцию,
кэш или набор случайно закоммиченных MIDI. Фильтры по расширению
`*.mid`/`*.midi` для всей истории применять нельзя: они затронут нашу подборку.
Для удаления посторонних файлов указывайте только их проверенные пути.

## Добавление музыки

1. Проверить права на само произведение, аранжировку и конкретный MIDI.
2. Для этой подборки выбирать редакцию с явным Public Domain или CC0 на странице
   автора или издателя; одной надписи в чужом MIDI недостаточно.
3. Сохранить MIDI и оригинальные исходные ноты с уведомлениями. Если MIDI
   создан из нот, сохранить команду или скрипт преобразования.
4. Добавить в manifest.json автора набора, издание, страницу подтверждения,
   дату проверки и SHA-256. Для нового источника отдельно зарегистрировать
   проверенные URL в src/public-library.mjs. Только записи manifest.json входят в сборку.
5. Запустить npm run catalog:public и npm test.

Не добавлять сюда файлы из личной коллекции downloads/ автоматически.
Техническая доступность по URL и наличие CORS не подтверждают права.

Это документированная подборка по заявлениям первоисточника, а не гарантия
отсутствия любых претензий во всех юрисдикциях. При получении обоснованной
претензии нужно перепроверить конкретную запись.
